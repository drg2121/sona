# Sona

Cărțile tale, citite cu voce naturală. Aplicație web (PWA) pe care o pui pe ecranul telefonului
din Safari sau Chrome („Adaugă pe ecranul principal”); merge și cu ecranul blocat.

- intri cu Google sau cu email; ține minte unde ai rămas, pe orice dispozitiv
- istoric, favorite, viteză, temporizator de somn
- text sincronizat cu vocea, ca să urmărești citirea

Cărțile se generează și se publică din Studio, de pe Mac. Audio și textele stau private în
Firebase; doar conturile aprobate le pot asculta. Repo-ul conține doar codul aplicației.
