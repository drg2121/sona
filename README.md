# Cărți audio

Aplicație web (PWA) pentru ascultat cărți citite cu voce naturală. Se instalează pe telefon
din Safari/Chrome („Adaugă pe ecranul principal”) și merge și cu ecranul blocat.

- cont personal: ține minte unde ai rămas, pe orice dispozitiv
- istoric, favorite, viteză, temporizator de somn
- text sincronizat cu vocea (urmărești citirea)

Cărțile se generează și se publică din Studio, de pe Mac. Audio și textele stau private
în Firebase; doar conturile aprobate le pot asculta. Repo-ul conține doar codul aplicației.
